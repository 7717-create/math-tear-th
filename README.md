# MATH TEAR TH

เกม RPG ภาษาไทยสำหรับมือถือแนวนอน เวอร์ชันทดสอบ

[เปิดเล่นเกม](https://7717-create.github.io/math-tear-th/)

เดินด้วยจอยซ้าย แตะโต้ตอบเมื่ออยู่ใกล้สิ่งของ ต่อสู้ด้วยปุ่มตัวเลข: ตอบถูกเพื่อโจมตี ตอบผิดหรือหมดเวลาจะถูกโจมตี แตะแปลงเพื่อปลูกและเก็บเกี่ยว

บันทึกอัตโนมัติในเบราว์เซอร์แต่ละเครื่อง เซฟจาก localhost ไม่ย้ายไปเว็บไซต์โดยอัตโนมัติ

## สถานะ

นี่คือรุ่นทดสอบระหว่างพัฒนา ระบบเผ่าพันธุ์ การปรับแต่งตัวละคร สมดุลและหน้าจอบางส่วนยังอยู่ระหว่างปรับตามข้อกำหนดฉบับใหม่

## เทคโนโลยี

Phaser + TypeScript + Vite เผยแพร่เฉพาะไฟล์สำหรับเล่นเกม
